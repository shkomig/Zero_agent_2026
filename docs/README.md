# docs/

Screenshots and media for the project README.

To add the demo image, save your UI screenshot here as **`welcome.png`** (and
optionally **`research.png`** showing `/research` with the live TaskList). The main
README's "Demo" section references these paths, so once the files exist the images
render automatically on GitHub.

Recommended: 1200–1600px wide, PNG, the dark theme.
